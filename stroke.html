Overview

Analyser les facteurs associés aux AVC et construire un modèle de prédiction permettant d’identifier les profils à risque.

Ce que j’ai réalisé

  • Nettoyage et préparation du dataset médical
  • Analyse exploratoire des facteurs de risque
  • Entraînement et comparaison de modèles ML
  • Création d’un dashboard de visualisation

Stack

Python Pandas Scikit-learn Machine Learning Data Visualization Dashboard

Turning healthcare data into actionable insights.

Approach

Une démarche en 3 étapes : préparation des données → modélisation → analyse des résultats.

1) Data Preparation

Preprocessing
  • Nettoyage des données et traitement des valeurs manquantes
  • Analyse des variables : âge, glucose, hypertension, BMI...
  • Préparation du dataset pour la classification

2) Machine Learning Models

Modeling
  • Entraînement de plusieurs modèles de classification
  • Évaluation avec AUC, Recall et F1-score
  • Sélection du modèle le plus performant

3) Analysis & Dashboard

Insights
  • Analyse des facteurs influençant le risque d’AVC
  • Création de visualisations interprétables
  • Présentation des résultats dans un dashboard

Results

Les résultats montrent les tendances principales du dataset et les performances des modèles développés.

Main Insights

  • L’âge est un facteur fortement associé au risque d’AVC
  • Certains facteurs médicaux augmentent significativement le risque
  • Comparaison objective des performances des modèles ML
