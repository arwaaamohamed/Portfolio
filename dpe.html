Vue d’ensemble

Objectif : fiabiliser la donnée DPE (cohérence, manquants, outliers) et produire des analyses exploitables.

Ce que j’ai fait

  • Quality checks : règles, anomalies, doublons, manquants
  • Préparation : imputation, encoding, scaling, feature selection
  • EDA : segmentation (type bâtiment, zone, isolation)
  • Restitution : rapports + slides (format portfolio)

Stack

Python SQL Data Cleaning Validation Power BI OLAP

Good analytics starts with reliable data.

Approche

Une démarche en 4 phases : audit qualité → préparation → analyses → restitution.

1) Audit Data Quality

Profiling
  • Manquants, doublons, incohérences, valeurs extrêmes
  • Règles de cohérence (surfaces, étiquettes, énergie)
  • Harmonisation & nettoyage

2) Pipeline de préparation

Preprocessing
  • Imputation (KNN / MICE selon les besoins)
  • Scaling / normalisation (robust, power transform…)
  • Encoding (ordinal + one-hot) + sélection de variables

3) Analyses & insights

Insights / BI
  • EDA : patterns par zone, type de bâtiment, isolation
  • Comparaison des performances énergétiques
  • Identification des tendances et leviers d'amélioration

4) Restitution & livrables

Reporting
  • Rapports documentant chaque phase
  • Présentation synthétique du projet
  • Graphiques et résultats prêts pour la restitution

Résultats

Quelques insights types + ce que le projet démontre en compétences data.

Insights

  • Comparaison consommation selon type de bâtiment
  • Impact zone climatique / isolation sur la performance
  • Priorisation des leviers (chauffage, ventilation…)

Analyse orientée décision et restitution.
